# Titanic — Machine Learning Study

## Português

Estudo exploratório de aprendizado de máquina utilizando o conjunto de dados **Titanic**. Este repositório documenta um experimento em notebook Jupyter; não é um modelo publicado como serviço.

### Conteúdo

- [Notebook — Titanic, Machine Learning e Deep Learning](./Titanic_%3E_Machine_learning_%3E_Deep_learning.ipynb)

### Como explorar

1. Abra o notebook no Jupyter ou no Google Colab.
2. Confira as importações e os requisitos das primeiras células.
3. Disponibilize os dados necessários conforme as referências internas do notebook.
4. Execute as células em ordem e avalie resultados, métricas e limitações.

> Este repositório ainda não inclui ambiente de execução versionado, testes automatizados ou relatório de métricas reproduzíveis. Portanto, nenhum resultado de acurácia é anunciado neste README.
